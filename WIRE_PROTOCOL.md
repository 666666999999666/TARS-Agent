# Wire Protocol

> Generated by `scripts/gen_protocol_doc.py`. **Do not edit manually.**

## Transport

- TCP loopback `127.0.0.1:7437` (override via `TARS_HOST` / `TARS_PORT`)
- Each message is one `\n`-terminated JSON line (NDJSON)
- Commands use JSON-RPC 2.0 (client → server); Events use `kind=event` envelope (server → client)

## Versioning and delivery

- `protocol_version` versions the IPC envelope; `event_schema_version` versions durable event payload semantics.
- Event delivery is ordered and at least once. Clients deduplicate by the global monotonic `cursor`.
- Adding optional fields is compatible. Removing, renaming, or changing field semantics requires a new event schema version.
- Unknown event types may be shown as generic JSON. Unsupported schema versions must surface a compatibility error and must not be interpreted as known data.

## Commands

All commands are sent as JSON-RPC 2.0 requests. The `type` field inside `params` is used for routing.
