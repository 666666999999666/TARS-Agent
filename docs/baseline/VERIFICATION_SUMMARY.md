> 本页保留早期 V1 的历史记录。`job-baseline-20260919` 的当前结果以[求职学习基准说明](JOB_BASELINE.md)为准；下文的旧验收和旧覆盖率不能替代新提交的检查或未完成的真实场景。

## 功能范围

- `tars chat` 连续聊天，`tars chat --resume` 恢复会话，`tars run --goal` 完成一次目标后退出客户端。
- CLI/TUI 共用后台 Core 和一套 AgentLoop；工具执行仍经过参数、权限与工作目录检查。
- SQLite 保存会话、运行、消息和持久事件；客户端退出不关闭 Core，任务取消需要等待资源清理。
- 支持 Docker 工具运行、子 Agent、受信 MCP 服务、Skill、笔记、压缩与只读 Web。
- reviewer 仅能读取和列目录。CLI 每次提交一行，多行粘贴显示限制见[已知限制](LIMITATIONS.md)。

## 质量要求

离线回归、Ruff、严格类型检查、协议与架构检查、文档检查、构建检查应通过。覆盖率最低要求保持为行 65%、分支 49%、综合 62%、改动行 80%；改动行对比仓库初始化提交，不能临时换成 HEAD。

仓库初始化提交只放元数据，后续提交保存源码。CI 使用完整历史，不依赖其他仓库或外部基准提交。

## 边界

- CLI 的单行使用流程已验证；Windows ConPTY 多行粘贴后可能缺少结果尾部或下一提示，具体显示原因尚未确认。
- 模型可能超时或返回协议错误；程序必须保存失败状态、显示错误并允许继续使用，不能宣称外部模型永不失败。
- 本地 MCP 验收不代表任意外部服务均可用；外部服务已经接受的操作不保证可以撤销。
- 原生 Windows Terminal 的特定字体和输入法未单独验收。学习和展示应以实际能够解释、验证的能力为准。
