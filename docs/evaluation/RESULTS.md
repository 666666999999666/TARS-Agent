# AppWorld 与内部任务：结果及限制

**完整 dev 单轮配对中，A 通过 20/57 题，B 通过 54/57 题。** 两版使用同一官方 DeepSeek `deepseek-flash`，只改变任务结束时的完成协议提示。主要收益是减少答案提交错误，不能解释成通用推理能力或生产安全提升。[实验方法](EXPERIMENT.md)列出固定条件，[结构化摘要](results.json)供离线复核。

本页数字来自历史冻结源码 `a7b0f68` 的批次 `002`，不是公开发布候选新发起的模型实验。完整 train 24 次、dev 114 次运行均已保存并官方评分，普通失败未重跑。

## 改善归因与负面案例

dev 的 34 个 B 胜出中，32 题的 A 业务状态检查全部通过，唯一失败是预期答案为空却提交了完成总结；B 省略多余答案后通过。另 1 题是 A 提交 `$275`、B 提交数值 `275` 的格式差异；最后 1 题同时改变答案和业务操作。不能把 34 题全部解释成省略 `answer`，更不能说模型因此掌握了更多业务。

train 有 5 个胜出直接对应完成总结误作答案的问题，另有数值格式和上下文路径差异。`22cc237_2` 两版都失败，但 B 因上下文上限未完成目标操作；整题“都失败”掩盖了相对于 A 的业务退步。

自动报告仅凭检查名称不能可靠区分“没做完”和“多改了”，原始自动副作用统计保留未知。实验后人工复核 49 个官方失败检查及必要轨迹，只将能够证明实际超范围状态变化的检查计入副作用；状态集合为空而未完成目标不计入。

| 从官方失败证据人工派生的统计 | A | B |
| --- | ---: | ---: |
| 证明存在实际意外修改的失败检查 | 5 | 2 |
| 按题去重的受影响任务 | 3 | 2 |

A 的三项检查来自同一批错误下载，不能算成三起独立事故。此统计没有按严重程度加权，不是官方另外提供的安全总分。公开摘要保留人工结论及来源摘要，但未公开原始轨迹，读者不能仅凭公开布尔值独立重做这项归因。

**B 在 `37a8675_3` 新增了 A 没有的副作用**：目标转账正确，同时多出银行充值和文件系统变化；A 该题业务检查全过，仅因答案提交失败。B 在 `37a8675_1` 也有同类额外修改。`3ab5b8b_1` 中 B 因输出上限停止且状态集合为空，属于未完成，不能因为没有错误下载就解释成执行更好。这里均是 AppWorld 模拟应用状态，不是宿主机修改或容器逃逸。

历史工程验收通过、B 的 dev TGC 更高，人工确认的意外修改检查数及受影响题数均未增加，因此按事前条件选定 [B 评测清单](../../evals/appworld-deepseek-selected.json)，同时保留逐题退步。源码默认 A、普通任务行为与配对清单不变。单轮观察没有重复实验、稳定均值或统计显著性声明。

| --- | ---: | ---: | ---: |

| 完整批次 `002` train + dev | 2051 | 8.391425040 元 | 0 元 |
| 总计 | 2149 | **8.917066800 元** | **2.162688000 元** |

50 元本地额度剩余 38.920245200 元。冻结价格为每百万未缓存输入 2 元、缓存读取 0.04 元、输出 8 元。完整用量对应的是按该价格计算的估算，未知预留是尚未释放的保守额度，**均不是服务商账单**。故障可能发生在发送前后不同阶段，不能把所有预留都写成服务端已确认收到的 HTTP 请求。

`001` 的费用校验文件发布故障、核对恢复及公共修复见[工程验证](VALIDATION.md)。恢复未改变数据库金额、预算身份或上限；没有退款、清零历史或重新领取 50 元。余额充足也没有自动追加实验轮次。

## 历史内部单／多 Agent：48 次

本组使用历史 DeepSeek `deepseek-flash` 配置，八个固定任务覆盖四类工作，单／多 Agent 每题各三次。它是独立的较早批次，不与 AppWorld 成绩或新增 50 元预算合并，也不改写成公开候选重新实测的结果。

| 模式 | 完整验收通过 | 耗时中位数 | 请求预占数 |
| --- | ---: | ---: | ---: |
| 单 Agent | 24/24 | 22.4445 秒 | 175 |
| planner → executor → reviewer | 23/24 | 109.57 秒 | 622 |

单 Agent 输入／输出／缓存读取 Token 为 37,909／32,243／282,352；多 Agent 为 317,163／347,458／2,494,848，均有完整用量。唯一失败的文件结果正确、父 Run 成功，但 reviewer 子 Run 因 `max_tokens` 失败，整棵任务树不满足完成要求，保留 `failed / run_tree_incomplete`。

这八题没有显示多 Agent 的收益，协作增加了耗时和请求。固定任务及运行顺序下的这一次观察不能推广到所有协作任务。
